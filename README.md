# Лабораторна робота №4: обчислення на кластері Apache Spark

Проєкт обробляє відкриті дані поїздок Divvy (`Divvy_Trips_2019_Q4.csv`, IV квартал 2019) за допомогою **PySpark**.

## Що зроблено

1. **Python-оточення** — віртуальне середовище `.venv`, залежності в `requirements.txt`, встановлено **PySpark** (`pip install pyspark`).
2. **`docker-compose.yml`** — кластер Spark на образах Bitnami: `spark-master` (порти **8088** → UI, **7077** → master), `spark-worker-1`, `spark-worker-2`. Томи `./jobs` та `./out` змонтовані на **усі** сервіси, щоб виконавці бачили CSV і могли записувати результати.
3. **Каталог `jobs/`** — тестові дані `Divvy_Trips_2019_Q4.csv` і скрипт **`process.py`** з читанням CSV та п’ятьма окремими функціями під кожне питання лабораторної.
4. **Каталог `out/`** — результати у форматі CSV (Spark пише папку з `part-*.csv` та службовими файлами; для зручності використано `coalesce(1)`, тобто один файл даних на завдання).

## Структура репозиторію

| Шлях | Призначення |
|------|-------------|
| `jobs/Divvy_Trips_2019_Q4.csv` | Вхідні дані для Spark |
| `jobs/process.py` | Логіка PySpark і запис у `out/` |
| `docker-compose.yml` | Підйом кластера |
| `requirements.txt` | `pyspark` |
| `out/<назва_завдання>/` | Вихідні CSV по кожному запиту |

## Як запустити

### Локально (без Docker)

```bash
cd /path/to/exercise-4-running-computation-on-spark-cluster
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
mkdir -p out
python jobs/process.py
```

### На кластері в Docker

```bash
docker compose up -d
docker exec -it spark-master spark-submit /opt/bitnami/spark/jobs/process.py
```

Після виконання результати з’являться у **`out/`** на хості (том `./out`).

За потреби шлях до CSV можна перевизначити змінною середовища `DIVVY_CSV`.

## Запитання та результати (Divvy Q4 2019)

Нижче — відповіді за згенерованими файлами в `out/`. Повні добові ряди для (a) та (b) див. у відповідних CSV (**92** дні даних у кварталі).

### a. Середня тривалість поїздки на день

- **Файл:** `out/avg_duration_per_day/part-*.csv`
- **Поля:** `trip_date`, `avg_duration_sec` (секунди).
- **Приклад:** 2019-10-01 — середня тривалість **≈ 1207.6 с**; 2019-10-02 — **≈ 909.5 с** (точні значення — у файлі).

### b. Скільки поїздок здійснено кожного дня

- **Файл:** `out/trips_per_day/part-*.csv`
- **Поля:** `trip_date`, `trips_count`
- **Приклад:** 2019-10-01 — **18 425** поїздок; 2019-10-02 — **9 882** (решта днів — у файлі).

### c. Найпопулярніша початкова станція за кожен місяць

- **Файл:** `out/popular_start_station_per_month/part-*.csv`
- Для **жовтня, листопада й грудня 2019** найбільше стартів з однієї станції — **Canal St & Adams St** (кількості стартів: **6564**, **3445**, **2928** відповідно).

### d. Трійка лідерів станцій за поїздками кожного дня (останні два тижні даних)

- **Файл:** `out/top3_stations_last_two_weeks/part-*.csv`
- Береться **останні 14 календарних днів** у наборі (включно з днем максимальної дати).
- **Поля:** `trip_date`, `rank` (1–3), `from_station_name`, `trips_count`.
- Детальна таблиця по кожному з цих днів — у зазначеному CSV.

### e. Чоловіки чи жінки їздять довше в середньому?

- **Файл:** `out/gender_avg_duration/part-*.csv`
- Ураховано лише записи зі статтю **Male** / **Female** (без порожніх значень).
- **Результат:** **жінки** в середньому їздять довше:
  - **Female:** **≈ 1101.95 с**
  - **Male:** **≈ 855.31 с**
